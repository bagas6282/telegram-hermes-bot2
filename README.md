# Telegram Hermes Bot (24/7 on Render)

Telegram AI Bot webhook deployment for Render.

## Environment Variables
- `TELEGRAM_BOT_TOKEN`: Your Telegram Bot Token from @BotFather
- `LLM_API_KEY`: API Key for LLM (e.g. OpenRouter or Gemini)
- `LLM_BASE_URL`: OpenAI-compatible API base URL (default: OpenRouter)
- `LLM_MODEL`: Model name (default: google/gemini-2.0-flash-001)
